# Names

A simple web app that displays names with a stylized visual effect.

## Usage

1. Open the app in a browser
2. Enter a comma-separated list of names when prompted
3. Names are displayed with animated styling in a hero section

## Features

- Splits multi-word names into individual styled spans
- Dynamic page title updates with entered names
- CSS-based visual effects with border overlays

## Tech Stack

- HTML/CSS/JavaScript
- Hosted via GitHub Pages
